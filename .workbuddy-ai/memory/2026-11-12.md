## 3D 猫咪头像：毛发 / 贴图 / 耳朵 这一轮

### 事故：工作区被 git 清空过两次
- 现象：`3d-init.js` 突然从 139KB 变回 280 行（最初那版球体猫），app.js 也回到 HEAD。
- 原因链：`git reflog` 显示 `checkout 3DProfile → 3DGaussianSplatting` → 又切回来 → `reset --hard origin/3DProfile`。
  中间有一个 `stash@{0}`，说明是「先 stash 再切分支再 reset」的外部操作（不是本会话执行的）。
- 恢复：`git cat-file -t a5184352`（悬空 stash 提交）→ `git checkout a5184352 -- .`。
- 现在所有改动提交在分支 **`wip/3d-avatar`**（9841874d / c85be68c），不再裸放在工作区。
- 教训：这个仓库随时可能被外部 git 操作重置。改完就提交到 wip 分支；动文件前先 `git stash list` 看一眼。

### 毛丝：两次错误的撒点方式
1. `addFurStrands` 按椭球半径撒点：椭球中心 (0,0,0)，躯干中心 (0,0.62,-0.06) —— 毛全长在脚边、埋在身体里。
2. `addSurfaceStrands` 从骨骼中心打射线求交：**骨骼中心在实体内部**，第一步 `t=0.06` 就判「命中」，
   毛根全埋进头骨 5cm，一根都看不见（之前「额头黑点」消失其实是毛根本没长出来）。
   而且密度按立体角分布，头顶密、脖子稀，会出现一条「发带」。
3. 最终方案 `addMeshStrands(mesh, boneList, count, colors, options)`：
   直接用蒙皮网格自己的顶点 + 法线，按 `skinWeight` 最大值的骨头分桶，每根骨头一个 InstancedMesh。
   密度均匀、法线准确、跟着骨骼动画走。顶点色做「根暗尖亮」渐变（`getStrandGeometry`）。

### 贴图：512px 画布上的笔触尺寸
- `makeCoatCanvas` 的 `size = 512`，整张脸在贴图上只有 ~180px，屏幕上也是 ~200px
  → **1px 的笔触等于没画**。之前的毛流笔触 len 4–17 / lineWidth 0.5–1.8 就是这个毛病。
- 现在 len 7–21 / lineWidth 1.0–2.5 / 每色 3000–4600 笔，按「簇」落笔（一簇 3–7 根、方向一致）。
- `drawPattern` 的 solid 分支原来是 9 个半径 90–180px 的大径向渐变 = 一脸水彩云（「面部纹理不对」的主因），
  改成 22 个半径 16–46px、透明度 0.055 的小斑。

### 圆柱 UV 的三个已知坑（补充）
- 胸白底边必须 ≥ v 0.27，u 半径 ≤ 0.06：前腿在 u 0.406/0.594、v 0.06–0.24，压下去就四条腿全白。
- 白袜子 ry 0.040 @ v 0.062；再大就顺着腿往上爬。
- 灰毛丝不能长在 v<0.17 的白袜子上（灰针扎白毛），所以 `addMeshStrands` 的 filter 直接砍掉。

### 耳朵
- 原来有「暗边 + 内耳」两个手摆椭球，耳骨一转，里面那个会从耳廓钻出来，在脸上留一块粉色。
  合成一个薄片（`earInner` 材质，scale 0.62/1.12/0.12，z 收到 0.030）。
- 脸上/耳边偶尔出现的**粉色小三角不是 bug，是「逗猫棒」道具**（`props.feather`），棕色杆子 + 粉色羽毛。
